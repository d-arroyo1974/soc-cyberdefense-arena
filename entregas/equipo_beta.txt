MISION 1: GESTION CUANTITATIVA DEL RIESGO DE CIBERSEGURIDAD
--------------------------------------------------------------------------------
1.1 Valoracion de Activo:
    - Activo: Servidor de Correo Corporativo (AV = $150,000 USD).
1.2 SLE:
    - EF = 50% (0.50).
    - SLE = AV * EF = $150,000 * 0.50 = $75,000 USD.
1.3 ALE inicial:
    - ARO = 1.0 (un incidente anual).
    - ALE_inicial = SLE * ARO = $75,000 * 1.0 = $75,000 USD / ano.
1.4 Mitigacion y Costo:
    - Control: Antispam Cloud + Filtro Anti-Phishing con Sandbox.
    - EF_mitigado = 10% (0.10).
    - ARO_mitigado = 0.2.
    - SLE_mitigado = $150,000 * 0.10 = $15,000 USD.
    - ALE_mitigado = $15,000 * 0.2 = $3,000 USD / ano.
    - Costo del Control = $10,000 USD / ano.
1.5 Analisis Costo-Beneficio (CBA):
    - CBA = (ALE_inicial - ALE_mitigado) - Costo_Control
    - CBA = ($75,000 - $3,000) - $10,000 = $72,000 - $10,000 = $62,000 USD / ano.
    - CBA positivo, inversion recomendada.
